脓毒症ICU预警AI演示系统 科研原型 · 第5期工程

本系统是面向临床演示的 Web 可视化外壳：将 POC1~POC4 原本只能在控制台查看的文本输出， 转为网页可视化界面，模拟一套 ICU 脓毒症预警系统的操作体验。 原型覆盖两大能力：多模态湖仓数据治理（Apache Iceberg ODS/DWD/ADS） 与 ICU 脓毒症 Guardrailed-Agent 预警（风险分级 + RAG 循证 + JEV 自检 + 护栏）。

本工程（POC-5）不包含任何业务计算：页面全部数据来自 POC1~POC4 运行后落盘的产物文件 （模拟患者 JSON、预警卡片、agent_trace.jsonl 审计日志、湖仓快照元数据与融合报告）； 网页按钮仅通过子进程触发外部工程入口脚本，绝不修改外部业务逻辑。

①

模拟患者管理

读取 sim_icu_data.json，展示 SIM_P001 / SIM_P002 / SIM_P003 三名模拟患者的基线与当前生命体征，选择患者发起 Agent 评估。
②

Agent预警演示

渲染 ICU 预警卡片：风险分级 L3 L2 L1、风险概率、恶化驱动因子、RAG 证据与 JEV 自检结果。
③

湖仓数据浏览

浏览 Iceberg 湖仓 ODS/DWD/ADS 三层产物，下拉选择历史快照，演示快照时间旅行与科研数据集可复现能力。
④

审计日志查看

汇总每一次 Agent 运行记录（患者、时间、风险等级、最终状态），可展开查看完整 agent_trace.jsonl 原始审计追踪。
